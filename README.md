# Mosaic theme documentation

Merchant documentation for the Mosaic Shopify theme by Shopupup, built with VitePress.

- Published at https://serm12.github.io/mosaic-docs/
- English pages are in `docs/`, Simplified Chinese pages in `docs/zh/`
- Pushing to `main` publishes the site through GitHub Actions

Run `npm ci`, then `npm run dev` to preview locally. Keep both languages in step, and describe only what the theme currently does.
