# Header and navigation

## Header

Select **Header** in the theme editor to set the logo, logo width on desktop and mobile, the menu, the color scheme and the scroll behavior.

## Transparent header

Turn on **Transparent header on homepage** so the header sits over your first section. You can also set which pages use it, the text and icon color, and an optional separate logo.

## Mega menu

A mega menu opens a full-width panel from a top-level menu item, showing its links in columns with optional promotion cards.

1. In **Online Store > Navigation**, create a menu with nested links under a top-level item.
2. In the theme editor, select **Header** and add a **Mega menu** block.
3. In **Menu item name**, enter the name of the top-level item exactly as it appears in the menu.
4. Set **Link columns** and **Promotion area width**.
5. Add up to 3 **Promotion card** blocks, each with an image, heading, link and image ratio.

## Announcement bar

Add messages with text and a link, and pick a color scheme.

## Footer

Add menu blocks, a heading and text, and pick a color scheme. You can also show payment icons and social links.
