# Products and cart

## Product page

Select **Product details** in the theme editor on a product page.

| Setting | What it does |
| --- | --- |
| Desktop gallery layout | Shows media as a carousel or as a grid on desktop |
| Show media thumbnails | Shows small previews under the gallery |
| Enable image enlargement | Opens images in a larger view |
| Keep product details visible while scrolling | Keeps the details column in view on desktop |
| Image ratio | Sets the shape of gallery media |

Reorder the blocks to change the details column: Title, Price, SKU, Variant picker, Purchase buttons, Description and Text. You can also add app blocks.

## Quick view

Turn on **Theme settings > Product cards > Quick view button**. Shoppers can then open a product in a popup and return to the same place. Dynamic checkout buttons are not shown in quick view.

## Cart drawer

The **Cart drawer** section opens the cart as a side panel. Use **Enable cart drawer** to turn it on or off, and pick a color scheme.

## Collection filters

Collections can show filters and sorting. In the **Collection** section, use **Enable filters** and **Enable sorting**. Choose the position in **Theme settings > Collection pages > Filter position**.

Which filters appear is managed in the Shopify **Search & Discovery** app. If no filters are configured there, none are shown.
