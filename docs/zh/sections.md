# 区块与内容块

区块（Section）是页面上的大模块，内容块（Block）是区块里的小部件，可以调整顺序。

## 可添加的区块

| 区块 | 用途 | 内容块 |
| --- | --- | --- |
| 幻灯片 | 大幅轮播横幅 | 幻灯片 |
| 图文区域 | 图片搭配文字 | 标题、正文、按钮 |
| 图片卡片 | 一排带链接的图片 | 图片卡片 |
| 精选商品 | 展示某个集合的商品 | 无 |
| 服务说明 | 简短的服务要点 | 服务项 |
| Countdown banner | 促销或上新倒计时 | Countdown |
| 商品系列网格 | 展示你的集合 | 无 |
| 自定义区域 | 自由布局 | 主题内容块 |

## 幻灯片

区块设置桌面和移动端高度、自动轮播、切换间隔，以及控制按钮的颜色方案。

每张幻灯片可以设置图片、可选的移动端图片、颜色方案、遮罩不透明度和内容对齐。幻灯片里可以添加并排序标题、正文、按钮和 Countdown 内容块。

::: tip
如果桌面图在手机上裁切不好，就添加一张 **移动端图片**。每种设备只下载自己需要的那张。
:::

## 倒计时

设置结束日期和时区、文字、链接和颜色方案。**When countdown ends** 决定结束后的行为，**Ended message** 设置结束后显示的文字。

## 自定义区域

添加主题内容块来搭建自己的布局。用 **组合** 内容块排列内容，可以设置布局方向、对齐和内边距。

## 间距

多数内容区块都有上下间距设置，移动端的内边距可以单独设置。
