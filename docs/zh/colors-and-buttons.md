# 颜色与按钮

## 颜色方案

颜色方案是一组有名称的颜色。每个区块选择一个方案，里面的背景、文字、标题、边框、按钮和提示信息都会跟随它。

在 **主题设置 > 颜色** 中创建和编辑方案。修改方案后，所有使用它的区块都会更新。

| 字段 | 用途 |
| --- | --- |
| 背景、背景渐变 | 区块背景 |
| 次级底色 | 次要的底色区域 |
| 正文文字、标题 | 正文和标题 |
| 边框与分隔线 | 线条和输入框边框 |
| 实心按钮、实心按钮文字 | 实心按钮的常态 |
| 实心按钮悬停、实心按钮悬停文字 | 实心按钮的悬停状态 |
| 描边按钮文字、描边按钮边框 | 描边按钮的常态 |

## 按钮悬停颜色的规则

- **实心按钮** 悬停时变成方案的悬停色。
- **描边按钮** 悬停时填充成方案的实心按钮色。
- 边框保持常态颜色，所以即使悬停色和页面背景相同，按钮也不会消失。

::: tip 自动互换颜色
把 **实心按钮悬停** 设成和 **实心按钮** 相同的颜色，悬停时按钮色和文字色就会自动互换。
:::

默认的悬停色是固定值。修改 **实心按钮** 后，记得同时检查悬停色，或按上面的方法设成相同颜色。

## 悬停填充动画

默认情况下，悬停时颜色会从按钮底部升起填充。要关闭它，取消勾选 **主题设置 > 按钮 > 悬停填充动画**，按钮颜色会改为淡入淡出。
