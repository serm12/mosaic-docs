# 主题设置

打开主题编辑器，点击齿轮图标。这里的设置对全店生效。

| 分组 | 控制内容 |
| --- | --- |
| 品牌 | 没有导航栏的页面（如礼品卡页）使用的 Logo，以及浏览器标签图标 |
| 颜色 | 各区块使用的颜色方案，详见[颜色与按钮](/zh/colors-and-buttons) |
| 字体排版 | 正文字体和字号、标题字体、六级标题和导航文字 |
| 页面布局 | 内容最大宽度，以及桌面端和移动端的左右边距 |
| 按钮 | 圆角、高度、内边距、边框、字体、文字大小、大小写和悬停填充动画 |
| 动画 | 滚动时显现内容 |
| 圆角 | 卡片、图片和表单输入框的圆角 |
| 商品卡片 | 布局、购物操作和颜色色板 |
| 徽章 | 促销和售罄徽章及其颜色 |
| 集合页 | 筛选位置 |
| 社交媒体 | 图标样式、是否在新标签页打开、账号链接 |

## 字体排版

每一级标题都有独立的字体、字号、行高、字间距和大小写。区块设置决定标题使用哪一级，所以修改 **标题 2** 会更新所有使用它的标题。

## 动画

**滚动时显现内容** 会让区块在进入屏幕时淡入。访客开启“减少动态效果”时会自动关闭，在主题编辑器里也不生效。

## 商品卡片

- **加入购物车按钮：** 直接加购。有选项的商品会跳转到商品页。
- **快速浏览按钮：** 在商品图上显示放大镜按钮，点击后在弹窗中打开商品。桌面端悬停卡片时出现，触屏设备上始终显示。
- **颜色色板：** **视为颜色的选项名称** 用逗号分隔。使用 Shopify 原生色板的选项始终包含在内。

## 徽章

促销徽章上的节省金额只对没有选项的商品显示。

## 社交媒体

填写以 https:// 开头的完整链接。留空的项目不显示。
