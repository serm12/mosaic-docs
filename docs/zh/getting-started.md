# 快速开始

## 把主题添加到店铺

1. 在 Shopify 后台进入 **在线商店 > 模板**。
2. 在模板库中选择 **添加模板 > 上传 zip 文件**。
3. 选择 Mosaic 的 zip 文件，等待上传完成。
4. 点击 **自定义** 打开主题编辑器。

在点击 **发布** 之前，线上店铺不会有任何变化。

## 推荐的设置顺序

1. **主题设置 > 颜色：** 先设置颜色方案，所有区块都会用到它。
2. **主题设置 > 字体排版：** 选择正文和标题字体。
3. **导航栏：** 添加 Logo 和菜单，详见[导航栏与菜单](/zh/header-and-navigation)。
4. **页脚：** 添加菜单和社交媒体链接。
5. **首页：** 编辑幻灯片，并添加需要的区块，详见[区块与内容块](/zh/sections)。
6. **商品页：** 用真实商品检查布局，详见[商品与购物车](/zh/products-and-cart)。

## 使用主题编辑器

- 侧边栏列出当前页面的所有区块。拖动可以排序，点击可以编辑。
- **添加分区** 用来插入新区块。部分区块还能添加内容块，比如幻灯片里的每一张。
- 齿轮图标打开 **主题设置**，这里的设置对全店生效。
- 用顶部的页面选择器切换首页、商品页、集合页等。
