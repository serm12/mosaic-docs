# 商品与购物车

## 商品页

在主题编辑器的商品页中选择 **商品详情**。

| 设置 | 作用 |
| --- | --- |
| 桌面图库布局 | 桌面端以轮播或网格展示媒体 |
| 显示媒体缩略图 | 在图库下方显示小预览图 |
| 允许放大图片 | 点击图片查看大图 |
| 滚动时固定商品信息 | 桌面端滚动时详情栏保持在视野内 |
| 图片比例 | 设置图库媒体的形状 |

调整内容块顺序可以改变详情栏的排列：标题、价格、SKU、变体选择器、购买按钮、描述和文本。也可以添加应用内容块。

## 快速浏览

开启 **主题设置 > 商品卡片 > 快速浏览按钮** 后，顾客可以在弹窗中查看商品，关闭后回到原来的位置。快速浏览中不显示动态结账按钮。

## 购物车抽屉

**购物车抽屉** 区块让购物车以侧边栏打开。用 **启用购物车抽屉** 开关，并选择颜色方案。

## 集合筛选

集合页可以显示筛选和排序。在 **商品系列** 区块中使用启用筛选和启用排序选项，在 **主题设置 > 集合页 > 筛选位置** 中选择位置。

具体显示哪些筛选项，要在 Shopify 的 **Search & Discovery** 应用中设置。那里没有配置时，页面上不会显示筛选。
