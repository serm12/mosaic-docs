# 导航栏与菜单

## 导航栏

在主题编辑器中选择 **导航栏**，可以设置 Logo、桌面和移动端的 Logo 宽度、菜单、颜色方案和滚动行为。

## 透明导航栏

开启首页透明导航栏后，导航栏会叠在第一个区块上方。你还可以设置哪些页面使用透明导航栏、文字和图标颜色，以及单独的 Logo（可选）。

## 大菜单

大菜单从顶级菜单项展开一个通栏面板，把子链接按列展示，并可以加促销卡片。

1. 在 **在线商店 > 导航** 中创建菜单，在顶级项下添加子链接。
2. 在主题编辑器中选择 **导航栏**，添加 **大菜单** 内容块。
3. 在 **菜单项名称** 中填写顶级菜单项的名称，要和菜单里完全一致。
4. 设置 **链接列数** 和 **促销区域宽度**。
5. 最多添加 3 张 **促销卡片**，每张可设置图片、标题、链接和图片比例。

## 通知栏

添加带文字和链接的消息，并选择颜色方案。

## 页脚

添加菜单内容块、标题和文字，并选择颜色方案。还可以显示支付图标和社交媒体链接。
