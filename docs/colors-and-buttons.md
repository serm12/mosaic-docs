# Colors and buttons

## Color schemes

A color scheme is a named set of colors. Each section picks one scheme, and everything inside it follows: background, text, headings, borders, buttons and messages.

Create and edit schemes in **Theme settings > Colors**. Changing a scheme updates every section that uses it.

| Field | Used for |
| --- | --- |
| Background, Background gradient | Section background |
| Raised surface | Secondary surfaces |
| Text, Headings | Body text and headings |
| Borders and dividers | Lines and field borders |
| Solid button, Solid button label | Solid buttons at rest |
| Solid button on hover, Solid button label on hover | Solid buttons on hover |
| Outline button label, Outline button border | Outline buttons at rest |

## How button hover colors work

- **Solid buttons** change to the hover colors of the scheme.
- **Outline buttons** fill with the solid button color of the scheme.
- The border keeps its resting color, so a button stays visible when its hover color matches the page.

::: tip Swap colors automatically
Set **Solid button on hover** to the same color as **Solid button**. On hover, the button and label colors then swap.
:::

The default hover colors are fixed values. If you change **Solid button**, review the hover colors too, or set them to match as described above.

## Hover fill animation

By default, a color fill rises over buttons on hover. To turn it off, clear **Theme settings > Buttons > Hover fill animation**. Button colors then fade instead.
