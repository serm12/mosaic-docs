# Getting started

## Add the theme to your store

1. In Shopify admin, go to **Online Store > Themes**.
2. Under the theme library, choose **Add theme > Upload zip file**.
3. Select the Mosaic zip file and wait for the upload to finish.
4. Choose **Customize** to open the theme editor.

Your live store does not change until you choose **Publish**.

## Recommended setup order

1. **Theme settings > Colors:** set up your color schemes first, because every section uses them.
2. **Theme settings > Typography:** choose your body and heading fonts.
3. **Header:** add your logo and menu. See [Header and navigation](/header-and-navigation).
4. **Footer:** add menus and your social links.
5. **Home page:** edit the slideshow and add the sections you need. See [Sections and blocks](/sections).
6. **Product page:** check the layout on a real product. See [Products and cart](/products-and-cart).

## Using the theme editor

- The sidebar lists every section on the current page. Drag to reorder, or select one to edit it.
- **Add section** inserts a new section. Some sections also accept blocks, such as the slides in a slideshow.
- The gear icon opens **Theme settings**, which apply across the whole store.
- Use the page selector at the top to switch between the home page, product pages, collections and more.
