# Sections and blocks

Sections are the large parts of a page. Blocks are the smaller pieces inside a section, and you can reorder them.

## Sections you can add

| Section | Use it for | Blocks |
| --- | --- | --- |
| Slideshow | A large rotating banner | Slide |
| Image with text | An image beside text | Heading, Text, Button |
| Image cards | A row of linked images | Image card |
| Featured collection | Products from a collection | None |
| Store highlights | Short service points | Highlight |
| Countdown banner | A sale or launch timer | Countdown |
| Collection grid | A list of your collections | None |
| Custom section | A free layout | Theme blocks |

## Slideshow

The section sets the desktop and mobile height, automatic rotation, the time between slides and the controls color scheme.

Each slide has an image, an optional mobile image, a color scheme, an overlay opacity and a content alignment. Inside a slide, you can add and reorder Heading, Text, Button and Countdown blocks.

::: tip
Add a **Mobile image** when your desktop image crops badly on phones. Each device downloads only the image it needs.
:::

## Countdown

Set the end date and timezone, the text, a link and a color scheme. **When countdown ends** chooses what happens at the end, and **Ended message** sets the text shown afterward.

## Custom section

Add theme blocks to build your own layout. Use a **Group** block to arrange content, with options for layout direction, alignment and padding.

## Spacing

Most content sections have top and bottom spacing settings, with separate padding on mobile.
