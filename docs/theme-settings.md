# Theme settings

Open the theme editor and choose the gear icon. These settings apply across the whole store.

| Group | What it controls |
| --- | --- |
| Brand | Logo for pages without a header, such as the gift card page, and the browser tab icon |
| Colors | Color schemes used by sections. See [Colors and buttons](/colors-and-buttons) |
| Typography | Body font and size, heading font, six heading levels, and navigation text |
| Page layout | Content width, and side margins on desktop and mobile |
| Buttons | Corner radius, height, padding, border, font, text size, letter case and the hover fill animation |
| Animations | Reveal content on scroll |
| Corners | Corner radius for cards, images and form fields |
| Product cards | Layout, shopping actions and color swatches |
| Badges | Sale and sold out badges and their colors |
| Collection pages | Filter position |
| Social media | Icon style, new tab behavior and account links |

## Typography

Each heading level has its own font, size, line height, letter spacing and letter case. Section settings choose which level a heading uses, so changing **Heading 2** updates every heading that uses it.

## Animations

**Reveal content on scroll** fades sections in as they enter the screen. It turns off automatically for visitors who prefer reduced motion, and inside the theme editor.

## Product cards

- **Add to cart button:** adds the product directly. Products with options link to their product page instead.
- **Quick view button:** shows a magnifier button on the product image and opens the product in a popup. On desktop it appears when hovering the card. On touch screens it is always visible.
- **Color swatches:** **Option names treated as color** is a comma separated list. Options with native Shopify swatches are always included.

## Badges

Savings text on the sale badge is shown only for products without options.

## Social media

Enter full URLs starting with https://. Empty fields are hidden.
